### 3.1 npc.ts(~100 行,纯 TS)

状态机简化版(无 A*,只跟距离直线走):

```ts
export type NpcState = 'idle' | 'moving' | 'occupying';

export interface NpcEntity {
  x: number; z: number;
  state: NpcState;
  targetOutletIndex: number;  // -1 = 无目标
  occupyTimer: number;        // occupying 阶段倒计时
  meshIndex: number;          // 对应 scene npcMeshes 数组 index
}

export function createNpcController(opts: {
  getOutletCount: () => number;
  getOutletPos: (i: number) => { x: number; z: number };
  isOutletOccupied: (i: number) => boolean;
  setOutletOccupied: (i: number, occ: boolean) => void;
  npcCount: number;
}): {
  entities: NpcEntity[];
  update: (dt: number) => void;
  reset: (seed?: number) => void;
};
```

状态机:
- `idle`:随机 2-5 秒后进 `moving`,选最近未占桩为目标(targetOutletIndex)
- `moving`:朝目标走(walkSpeed 略慢于玩家 2.2 m/s);到桩 0.8m 内 → `occupying` + setOutletOccupied(idx, true)
- `occupying`:停 8-15 秒(随机)→ setOutletOccupied(idx, false) → 回 `idle`
- 目标被玩家占了(isOutletOccupied(target) && 不是自己占的)→ 改选下一个空桩

**纯 TS 零依赖**,可单测。

### 4.1 audio.ts(~120 行)

WebAudio API 程序化合成,零素材文件:

```ts
export interface AudioOptions {
  onWin: () => void;       // 充电成功 SFX
  onLose: () => void;      // 没电失败 SFX
  onLowBattery: () => void; // 低电警报
  onAppToggle: (app: 'map'|'radar'|'query') => void;  // app 开关 SFX
}

export function mountAudio(): {
  playWin: () => void;
  playLose: () => void;
  playLowBattery: () => void;
  playAppToggle: (app: string) => void;
  startBGM: () => void;
  stopBGM: () => void;
} {
  // AudioContext 懒初始化(首次用户点击 overlay 后 resume)
  // BGM:简单 4 拍循环(synth pad + bass)程序化合成,用 OscillatorNode + GainNode + 循环 setInterval
  // SFX:
  //   win: 上升音阶 C5→E5→G5→C6,每音 80ms,方波
  //   lose: 下降低频锯齿波 200hz→50hz,500ms
  //   lowBattery: 间歇短哔 800hz,每 2 秒一次
  //   appToggle: 短"咔"1000hz 正弦 50ms
}
```

**BGM 极简**:4 拍循环,C minor 调,fm synth pad + walking bass。不做完整 Vice City 风格复刻(那要素材)。
