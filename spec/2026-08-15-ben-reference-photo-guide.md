# Ben — Tripo3D 参考图拍摄指南

日期：2026-08-15

## 目标

为 Tripo3D 准备统一的 PS2 日式动漫游戏风格参考资料。项目采用 C 路线：角色使用明显 toon outline，环境资产不使用厚重全局黑边，而是依靠硬边、清晰轮廓、平面色块和少量手绘结构线表达风格。

## 一、风格参考图

### 当前已有

- `Naruto: Ultimate Ninja 2/3` 菜单或宣传画面：用于确定暖色、线稿和整体动漫气质。
- Naruto 角色游戏截图：用于确定硬边、分色阴影、身体比例和角色描边。

这两张足够作为第一版风格基准。后续可从 Google 图片搜索补充 1-3 张实际游戏场景截图，优先使用以下关键词：

```text
Naruto Ultimate Ninja 3 PS2 gameplay stage
Naruto Narutimate Hero 3 environment
Naruto Ultimate Ninja 2 PS2 battle stage
CyberConnect2 PS2 anime game background
```

补充图应优先展示场景、建筑、地面、木材和道具，不要只收集封面、Logo 或角色立绘。

## 二、主角猫：必须拍摄

### 1. 主图：三分之四站立照

这是提交给 Tripo3D 的主要猫参考图。

- 猫自然站立或缓慢走动，不要强行摆姿势。
- 拍摄角度为正面三分之四，能看清脸、胸口、四条腿和尾巴。
- 手机镜头放在猫的胸口高度，避免从上往下俯拍。
- 猫的四只脚尽量都接触地面并完整可见。
- 尾巴不能被身体、家具或画面边缘遮住。
- 猫的耳朵、脚和尾巴不能被裁掉。
- 使用零食或玩具放在镜头旁，让猫抬头但保持站立。
- 连拍 10-20 张，选择最清楚、姿态最自然的一张。

### 2. 补充照：正面站立

用于确认脸部、胸口花纹、两只前腿和耳朵形状。

- 与猫正面平视拍摄。
- 保证身体基本对称且四脚可见。
- 不要求与主图完全相同时间拍摄。

### 3. 补充照：侧面站立

用于确认身体长度、背部线条、后腿和尾巴比例。

- 左右侧任选一面，优先选择尾巴不被遮挡的一面。
- 尽量让猫完整处于画面中央。
- 保持手机与猫身体平行，不要使用广角近距离贴拍。

### 拍摄环境

- 选择背景简单的位置，例如空墙、干净地板或单色家具前。
- 使用均匀自然光或明亮室内光，避免强烈顶光和背光。
- 不开滤镜、不用人像虚化、不加美颜。
- 避免镜子、电视、复杂医疗设备和大量杂物进入画面。
- 不要为了拍照抓住或固定猫；以猫安全和自然状态为先。

### 当前猫图的用途

现有坐姿猫图可以保留，适合用于：

- 毛色和花纹
- 脸型、眼睛、耳朵
- 胸口和前腿的颜色分布

它不适合作为唯一主图，因为坐姿遮挡了后腿和身体下半部，背景也比较复杂。新拍的三分之四站立照应作为 Tripo 主输入，现有照片作为外观补充参考。

## 三、环境资产参考图

每种资产准备一张主参考图即可开始，后续再补角度。

### 书架 `bookshelf`

- 正面或三分之四视角。
- 能看清层板数量、木框、背板和书脊色块。
- 书籍不要有清晰标题、Logo 或复杂装饰。
- 优先找有明显设计轮廓的动漫或游戏场景书架。

### 学习桌 `studyTable`

- 三分之四视角。
- 能看清桌面厚度、四条桌腿和桌面比例。
- 参考图中如果有椅子，prompt 中必须明确排除；游戏里的椅子由代码生成。

### 柱子 `column`

- 正面或三分之四视角。
- 能看清柱身、顶部和底部装饰。
- 不要带地板、台座或周围建筑连接件。

### 阅读桌 `readingTable`

- 三分之四视角。
- 能看清较小的桌面和单柱底座。
- 不要带椅子、地面或窗户墙体。

## 四、提交给 Ben 的文件顺序

每次做一个资产时，按下面顺序发送：

1. 资产名称，例如 `cat` 或 `bookshelf`。
2. 1 张主参考图。
3. 0-2 张补充角度图。
4. 你特别喜欢或特别讨厌的视觉特征。
5. 如果是猫，补充毛色、性格和是否需要项圈等信息。

Ben 会先检查风格和可生成性，再给 Tripo3D 的 image-to-3D prompt。未通过参考检查前，不进入生成步骤。

## 五、Tripo 前检查清单

- [ ] 主体完整，没有被裁切。
- [ ] 主视角能看清主要轮廓。
- [ ] 背景不会和主体混在一起。
- [ ] 图片没有文字、Logo 或无关物件。
- [ ] 参考图负责形体和配色，prompt 负责低模、材质和禁止项。
- [ ] 猫使用站立三分之四图作为主输入，当前坐姿照片只作外观补充。
- [ ] 环境资产不要求全局黑边，使用硬边、色块和少量手绘结构线。

## 六、简单验收标准

### 参考照片通过条件

满足以下 4 项即可交给 Tripo：

- [ ] 主体完整，猫的脸、四条腿和尾巴都能看见。
- [ ] 三分之四主图能一眼看出整体轮廓和站立姿态。
- [ ] 颜色和花纹清楚，照片没有严重模糊、滤镜或背光。
- [ ] 背景不会遮住主体，没有大量无关物件。

正面照和侧面照是加分项，不齐全也不阻塞第一次测试。

### Tripo 模型通过条件

满足以下 5 项中的前 4 项，就可以进入 Blender 后处理：

- [ ] 一眼看起来仍然是目标猫或目标资产。
- [ ] 轮廓清楚，符合 PS2 日式动漫低模感，而不是写实照片或毛发雕塑。
- [ ] 猫有完整身体、四肢和尾巴；环境资产没有明显缺件。
- [ ] 没有自动生成地板、平台、家具、椅子或其他无关物件。
- [ ] 材质和色彩基本落在暖色手绘风格范围内。

如果前 4 项有任何一项失败，先改 prompt 或换参考图重生成，不要急着做 Blender 后处理。
