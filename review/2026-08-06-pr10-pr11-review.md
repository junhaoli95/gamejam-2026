## 4. 需 Snake 关注 / 不阻塞 merge 的小毛疵

### 4.1 ⚠️ NaN 风险(thirdPersonController.ts minDist clamp)

David 加的 5 行 clamp:
```ts
const dir = tmp.subVectors(camera.position, headPos);
const dist = dir.length();
if (dist < CONFIG.camera.minDist) {
  dir.multiplyScalar(CONFIG.camera.minDist / dist);  // ← dist=0 → NaN
  camera.position.copy(headPos).add(dir);
}
```

**当 `dist === 0`**(玩家位置恰好 reset 到 camera damping 起点),`dir.multiplyScalar(1.4/0)` = NaN vector,copy 到 camera.position → camera NaN → rendering 崩。

实际触发概率:几乎为零(damp + lerp + 8 步采样几乎不会出 0)。但若用户 reset camera / teleport 玩家 / warm frame 不对,极端边界会爆。

**建议修复**(PR #12 顺手):`if (dist > 1e-6 && dist < CONFIG.camera.minDist)` 加守卫 → skip clamp 让 damp 自然回弹。3 字符 = 0 成本。

### 4.2 playerStats.ts 末尾缺 newline

`\ No newline at end of file` — POSIXy 毛疵。不阻塞,git diff 不友好。建议 PR #12 一并修。

### 4.3 commits 杨 PR #10 仍是英文

Sam §16-S3 列清楚:`startPercent=1.0` 显示 "100% / 3:00";若真按 master §3.4 叙事"开局 1%" 应 `startPercent=0.01` 但 sec 单位要换算 `*18000`(180s 是真 1% 用满电时间)。
